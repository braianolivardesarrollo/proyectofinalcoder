# INSERV3D

Proyecto final del curso de Desarrollo Web de Coderhouse 2026.

## Descripción

INSERV3D es una página web creada para una empresa de impresión 3D. 
El sitio presenta información sobre la empresa, sus servicios, productos, preguntas frecuentes y un formulario de contacto.

El objetivo del proyecto fue aplicar los conocimientos aprendidos durante el curso utilizando HTML, CSS, SCSS y Bootstrap.

## Tecnologías utilizadas

- HTML5
- CSS3
- SCSS
- Bootstrap
- JavaScript (Bootstrap)

## Características

- Diseño responsive.
- Uso de componentes de Bootstrap.
- Organización de estilos con SCSS.
- Navegación entre diferentes páginas.
- Formulario de contacto.
- Optimización básica con etiquetas meta.
